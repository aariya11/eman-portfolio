# EMAN TRADES — Premium Trading Portfolio

A luxury digital portfolio and research archive for **EMAN TRADES**, a female professional trader, market analyst, and financial strategist.

Designed with the art direction and editorial refinement of an elite creative studio fused with the precision of institutional finance.

---

## Brand Direction & Visual Identity

- **Palette**: Obsidian Black (`#070708`), Charcoal (`#121215`), Warm Ivory (`#F5F2EB`), Champagne Gold (`#C9A96E`).
- **Typography**:
  - Editorial Headlines: `Cormorant Garamond` (High-contrast luxury serif)
  - Navigation & UI: `Plus Jakarta Sans` (Modern geometric sans)
  - Financial Telemetry: `JetBrains Mono` (Institutional monospace)
- **Texture**: Dynamic SVG film grain overlay.

---

## Features

- **Hero Experience**: Immersive cinematic opening with bespoke editorial portrait, staggered typography reveals, and quick CTAs.
- **Custom Magnetic Cursor**: Physics-based trailing cursor with contextual states (`VIEW`, `EXPLORE`, magnetic hover snap).
- **Live Market Telemetry**: Real-time status indicator calculating global market hours and session overlaps (London, NY, Tokyo, Weekend Settlement) based on UTC time.
- **Atmospheric Soundscape**: Optional generative ambient drone (432Hz harmonic room tone) built with the Web Audio API. Muted by default.
- **Institutional Performance Graphics**: Verified metrics with audit sources, an interactive SVG equity curve with point inspection, and an audited monthly compounding returns matrix.
- **Selected Trade Case Studies**: Deep-dive breakdowns across Precious Metals, FX, and Equities with annotated candlestick diagrams and a full-screen zoom modal (`ChartModal`).
- **Trading Journal**: Institutional essays with an integrated full-bleed distraction-free reading modal (`ArticleReaderModal`).
- **CMS Content Architecture**: Clean TypeScript data layer in `src/data/` for easy updates to profile, philosophy, markets, case studies, performance, and journal articles.
- **SEO & Structured Data**: Open Graph, Twitter cards, dynamic `sitemap.xml`, `robots.txt`, and Schema.org `Person` JSON-LD.

---

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Audio**: Native Web Audio API

## Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
